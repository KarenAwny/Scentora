# 👑 Be Special — خادم الباك إند ولوحة التحكم الإدارية (Node.js Backend & Admin)

باك إند خفيف وسريع ومبني بالكامل بـ **Node.js** بدون الحاجة لتثبيت قواعد بيانات خارجية معقدة. يتيح لك التحكم الكامل في متجر العطور وإدارته من خلال واجهة مستخدم إدارية فاخرة (Admin Dashboard).

---

## 🚀 طريقة التشغيل السريعة

يمكنك تشغيل الباك إند بأحد الطرق التالية:

### 1. من المجلد الرئيسي للمشروع:
```bash
npm run backend
```

### 2. أو بالدخول إلى مجلد `backend`:
```bash
cd backend
node server.js
```

بمجرد التشغيل، ستظهر لك الروابط:
- **🎛️ لوحة التحكم الإدارية:** [http://localhost:5000/admin](http://localhost:5000/admin)
- **📡 خادم الـ API للمتجر:** [http://localhost:5000/api](http://localhost:5000/api)

---

## 🌟 ميزات التحكم في الموقع ككل

### 1. 🧴 إدارة المنتجات والعطور (Products):
- **إضافة عطور جديدة:** بالاسم العربي والإنجليزي، الماركة، السعر، السعر قبل الخصم، نسبة الخصم، الحجم، ووصف العطر.
- **رفع واختيار الصور:** يمكنك رفع صورة عطر جديدة من جهازك مباشرة إلى مجلد `public/perfumes` بضغطة زر، أو الاختيار من الصور الموجودة مسبقاً مع معاينة فورية للصورة.
- **تعديل وحذف المنتجات:** تحديث أي تفاصيل، وتفعيل أو تعطيل التوفر في المخزون (In Stock / Out of Stock)، وتعيين العطر كـ "الأكثر مبيعاً" (Best Seller).
- **مزامنة فورية:** أي تعديل في المنتجات يتم حفظه في `backend/data/products.json` ويُحدّث فوراً ملف `src/data/products.js` لتظهر التغييرات على المتجر مباشرة بدون إعادة بناء.

### 2. 📦 إدارة الطلبات (Orders Management):
- استقبال تلقائي لكافة الطلبات المنفذة عبر المتجر (Checkout).
- تفاصيل العميل كاملة: الاسم، الهاتف، العنوان، المدينة، والبريد الإلكتروني.
- تفاصيل المنتجات المطلوبة والإجمالي وطريقة الدفع ونوع التوصيل.
- تحديث فوري لحالة الطلب:
  - ⏳ قيد الانتظار (Pending)
  - ⚙️ قيد التجهيز (Processing)
  - 🚚 تم الشحن (Shipped)
  - ✅ تم التسليم (Delivered)
  - ❌ ملغي (Cancelled)

### 3. 💬 صندوق الرسائل واستفسارات الزوار (Contact Messages):
- استقبال رسائل نموذج "تواصل معنا" المنفذة على المتجر.
- الاطلاع على الاسم، البريد، الموضوع، وتفاصيل الرسالة.
- إمكانية حذف الرسائل بعد معالجتها.

### 4. 📬 مشتركو النشرة البريدية (Newsletter Subscribers):
- تجميع إيميلات الزوار المشتركين في النشرة الإخبارية.
- زر بضغطة واحدة لنسخ كافة البريد الإلكتروني لاستخدامها في الحملات الإعلانية والتسويقية.
- إمكانية حذف أي بريد.

### 5. ⚙️ إعدادات الموقع العام والبانرات (Site Settings):
- اسم المتجر والشعار (بالعربية والإنجليزية).
- شريط الإعلانات العلوية (Announcement Bar).
- عناوين ونصوص البانر الرئيسي (Hero Section).
- معلومات التواصل: رقم الهاتف، الواتساب، البريد الإلكتروني، وعنوان المعرض.
- الحد الأدنى للشحن المجاني (Free Shipping Threshold).

## 📁 هيكلية ملفات الباك إند (`backend/`)

```
backend/
├── data/                    # قواعد البيانات بصيغة JSON خفيفة وسهلة النقل
│   ├── products.json        # بيانات جميع العطور
│   ├── orders.json          # الطلبات الواردة
│   ├── settings.json        # إعدادات ونصوص الموقع
│   ├── messages.json        # رسائل الزوار
│   └── subscribers.json     # مشتركو النشرة البريدية
│
├── public/
│   └── admin/
│       └── index.html       # لوحة التحكم الإدارية الفاخرة بالكامل
│
├── package.json             # تعريف حزمة الباك إند وأوامر التشغيل
├── server.js                # خادم Node.js مع كافة مسارات الـ API والرفع والتحكم
└── README.md                # دليل الاستخدام
```

## 🔌 مسارات الـ API المتاحة (RESTful Endpoints)

| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/stats` | `GET` | إحصائيات عامة (المبيعات، عدد الطلبات، المنتجات، الرسائل) |
| `/api/products` | `GET` | جلب قائمة المنتجات مع إمكانية الفلترة والبحث |
| `/api/products/:id` | `GET` | جلب تفاصيل عطر محدد |
| `/api/products` | `POST` | إضافة عطر جديد ومزامنته فوراً |
| `/api/products/:id` | `PUT / PATCH` | تعديل بيانات عطر |
| `/api/products/:id` | `DELETE` | حذف عطر |
| `/api/upload` | `POST` | رفع صورة عطر جديدة وحفظها في `public/perfumes` |
| `/api/images` | `GET` | قائمة أسماء الصور المتوفرة في مجلد العطور |
| `/api/orders` | `GET` | جلب كافة طلبات الشراء |
| `/api/orders` | `POST` | إنشاء طلب جديد (يستخدم من صفحة Checkout) |
| `/api/orders/:id` | `PATCH / PUT` | تحديث حالة الطلب |
| `/api/orders/:id` | `DELETE` | حذف طلب |
| `/api/settings` | `GET` | جلب إعدادات الموقع |
| `/api/settings` | `PUT / POST` | تحديث إعدادات الموقع ونصوصه |
| `/api/messages` | `GET` | جلب رسائل الزوار |
| `/api/messages` | `POST` | إرسال رسالة جديدة (من صفحة Contact) |
| `/api/messages/:id` | `PATCH / DELETE` | تحديث أو حذف رسالة |
| `/api/subscribers` | `GET / POST` | جلب أو تسجيل مشترك جديد في النشرة |
| `/api/subscribers/:id` | `DELETE` | حذف مشترك من النشرة |
